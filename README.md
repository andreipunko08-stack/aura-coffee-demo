# AURA COFFEE

Адаптивный сайт вымышленной кофейни для портфолио веб-разработчика. На странице есть рассказ о кофейне, шесть напитков с ценами в евро, галерея и демонстрационные адрес и расписание.

## Запуск

Откройте `index.html` в браузере. Сохраните `styles.css`, `script.js` и папку `assets` рядом с ним. Сервер, сборка, подключение к сети и API-ключи не нужны.

## Устройство проекта

- `index.html` содержит все разделы страницы и якорную навигацию.
- `styles.css` отвечает за адаптивную вёрстку, состояния фокуса и поддержку системной настройки уменьшенного движения.
- `script.js` управляет мобильным меню. Оно закрывается при выборе раздела или нажатии Escape. При отключённом JavaScript ссылки остаются доступны.
- `assets/` содержит созданные для демонстрации иллюстрации в стиле кофейной фотографии. Они сгенерированы, поскольку загрузка фотографий из открытого источника была недоступна.
